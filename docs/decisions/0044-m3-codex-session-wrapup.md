# ADR 0044 · M3 Codex 会话与确认式收尾

- 状态：已确认，待实现（2026-09-07）
- 范围：M3 带上下文启动与会话收尾
- 前置：M2、P2-02（ADR 0043）

## 决策

1. M3 默认交互式执行器为 Codex；Claude Code 保留为可选适配器，不作为本轮交付前置条件。
2. 启动时按 PRD 3.2.3 的固定顺序生成严格限界的上下文包；完整会议逐字稿不进入默认上下文。
3. 会话结束由收尾适配器生成脱敏的待确认草稿，草稿包含拟更新的项目状态、下一步、阻塞和工作记录。
4. 只有用户明确确认后，才执行 vault 原子写、自动提交和后续普通同步；未确认草稿不得写回、push 或覆盖已有内容。
5. 沿用现有锁、原子写、同步保护、双父恢复和脱敏审计边界；不新增云服务，P2-03 仍未授权。

## 验收

最小纵向切片必须完成：从一个项目档案生成上下文包、启动一次 Codex 会话、结束后生成草稿，
用户确认后更新主笔记与工作记录并留下 Git 留痕；取消确认时 vault 与 Git 均不变。真实验收以
人工补写比例低于 20% 为目标。
