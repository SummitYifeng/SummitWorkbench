# SummitWorkbench Web 使用指南（纯 Web 版）

> 适用版本：v0.2 · 本指南**不需要命令行**，所有操作都在浏览器里完成。
> 本指南也**内置在工作台顶部的「指南」页签**（内容与本文档同步，离线可看）。
>
> 工作台 = 你的本地执行管理层 + 第二大脑：记一笔 → 批一轮 → 喂一场会，一个页面闭环。
> 纯本地运行（127.0.0.1），数据只存在你的 Mac 上，不上传任何内容。

## 1. 打开工作台（不用敲命令）

- 从**「应用程序」文件夹或启动台**打开 **SummitWorkbench**（已正式安装在
  `/Applications/SummitWorkbench.app`，不在桌面）。App 与开发仓库**自动链接**：每次改造后
  只需退出重开 App 就是新版，无需重装或重新链接。
- 首次打开若被系统拦截（未签名应用）：右键点图标 → 「打开」→ 再点「打开」即可。
- 打开后弹出一个独立窗口显示工作台；**服务跟着 App 一起活着**，关掉窗口也不影响运行。
- 面板已开着时，直接用浏览器访问 http://127.0.0.1:8787 也能进入。

> 说明：工作台以「后台代理」方式运行，**不会出现在程序坞**（所以没有图标弹跳的烦恼）。
> 想再打开窗口：从「应用程序」打开 SummitWorkbench（服务已在跑时会直接弹出窗口），或直接
> 访问 http://127.0.0.1:8787。

> 退出工作台（停止本地服务）：点面板顶栏右上角的 **「退出」** 按钮（会先弹确认），
> 服务随即停止并关闭窗口。下次要用再从「应用程序」打开 App 即可。

顶部有五个页签：**「今日」（默认）| 「审批」| 「第二大脑」| 「项目」| 「指南」**。下面分页说明。

## 2. 「今日」页（默认首页）

打开第一眼，从上到下就是今天该做的事：

### ① 快速捕捉框（最顶部）

- 输入一行，按回车即记入全局 inbox，不跳转不刷新。
- 系统会自动判断这是**承诺**（要去做的事）还是**想法**（灵光/备忘），并识别截止日期；右下角会弹出提示，如「已记入全局 inbox · 承诺（截止 2026-09-10）」。
- 想关联项目就写 `#项目名`（用已建档项目的名字或别名），例如：`周三前给老王样章 #排版`。
- 即使 AI 没配置/超时，内容也会按「想法」安全保存，**永远不会丢**。

### ② 待确认审批卡片

- 有积压时显示橙色卡片：「N 条待确认 · 最老已等待 X 天」+「去处理 →」按钮，一键跳到审批页。
- 处理干净后变绿色「审批已清空」。

### ③ 导入会议纪要（拖拽区）

- 把飞书导出的逐字稿（`.md` / `.txt`，带说话人+时间戳）拖进虚线区，或点「点击选择文件」。
- 导入后**全自动**：归档原文 → 结构化笔记 → 提取项进入审批页；结果区回显「处理 N / 跳过 N / 失败 N / 生成候选 N」和预估费用。
- 文件名建议 `YYYY-MM-DD-会议标题.txt`（日期和标题的来源）。
- 自动处理只到「生成候选进审批页」；**批准写回仍要你在审批页逐条确认**——系统不会未经你同意改动项目和飞书任务。

### ④ 项目推进卡（只显示你在工作台的项目）

- 这里的卡片**不是** `~/Documents/Work` 下所有文件夹的目录——只有**已建档且「在工作台」的项目**会显示，避免项目文件夹多了以后首页被几十上百张卡片淹没。
- 每张卡：git 未提交/领先落后、项目 inbox 积压、主笔记里的「下一步」；有动静的卡片左侧高亮成警告色。
- **「新文件夹」横幅**：当工作目录里出现还没建档的项目文件夹时，项目区顶部会出现一条提示（不占卡片位），逐条可点 **「加入工作台」**（建档并出现在推进卡）或 **「归档」**（记录为已归档、不再提示）。处理完横幅即消失。
- 想调整哪些项目上首页：每个在工作台的项目卡片右下角都有 **「归档」** 按钮——点它、确认后
  项目即从首页消失（文件夹与笔记不动），想找回时去「项目」页点「加入工作台」即可恢复；
  批量管理走标题行右侧的 **「管理全部 →」**。

### ⑤ 今日简报（日程优先视图）

- 每天 08:00 自动生成；没生成时显示「⚡ 现在生成（约 30 秒）」按钮，点一下立即生成。
- 简报是当天晨间指挥台，从上到下分四层：
  1. **会议**：左侧固定时间列，已过去的会议自动淡化。
  2. **待办任务**（主清单，按截止紧迫度排序）：每行左侧是**截止徽章**——今天到期（红）/ 剩 1–2 天（琥珀）/ 一周内（蓝）/ 更远只看日期（灰）；行尾带 **「近期承诺 · #N」** 彩色注解的，是 AI 挑出今天最该推进的**今日优先**项（序号即推荐顺序，注解直接标在对应任务行上，与清单合一、不重复列两遍）。**每行最右有一个小圆钮「✓」**——点它就在飞书中把该任务标记为已完成（写回飞书任务本体），该行随即从待办消失并计入下方「最近完成」，无需切去飞书。
  3. **需要行动 · 任务清单之外**（有才显示）：不在飞书任务清单里的行动——如「提交 XX 的未提交改动」（git 未提交）、项目下一步、inbox 积压等，附分类注解与来源。
  4. **AI 提议（非事实）** 与 **最近完成**：默认折叠成一行（带条数），点开查看。
- 降级日（采集源失败 / 排序回退）简报顶部会出现黄色健康度提示；有待确认提取时也有提示条可直达「审批」页。
- vault 里的 Markdown 原文不变（Obsidian 里读到的还是原来那份简报）。

## 3. 「审批」页

### 单条候选操作

- **✓ 批准**：写回目标（项目主笔记 / 飞书任务 / inbox），点击即生效，无需整页刷新。
- **✗ 拒绝**：归档为忽略项。
- **↺ 改回待确认**：误操作可撤回。
- **修改**：展开表单可改正文、目标项目、落点（route）、截止日期，保存后即时生效。
- 依据或目标项目缺失的候选会显示「⚠ 暂不可批准写回」——这是缺信息，不是故障。
- 截止日期早于今天的待确认候选会在元信息标注「已过期」。

### 批量操作

- 每个会议分组标题右侧有「✓ 全批 / ✗ 全拒」：一键把该组**待确认**条目全部批准 / 全部拒绝（已裁决的条目不受影响）。
- 工具栏「一键拒绝过期项」：把截止早于今天的全部待确认条目批量置为拒绝（如清理测试会议的过期数据）。
- 工具栏「预演应用」：弹窗展示零写入的 DRY-RUN 计划（每条候选要去哪）；「应用（写回）」对全部已批准条目执行写回。

### 清理测试/旧会议（CLI）

- `wb review sweep`：预演列出将退役的会议笔记与候选数（零写入）。
- `wb review sweep --apply`：执行——该会议候选批量拒绝、笔记状态置 ignored（正文原文保留）、任务状态收口；之后 `wb review refresh` 不会再捞回它们。
- `wb review sweep --before 2026-08-28 --apply`：只清理会议日期早于 2026-08-28 的旧会议。
- 新导入会议请用收紧后的提取（prompt v3）：只有拍板的决策和「谁、何时前、做什么」明确的行动项才进审批页。

## 4. 「第二大脑」页

- 问答式追问：先问一句（如「网课项目最近的决策是什么？」），回答分「事实（带来源）」与「建议（模型推断）」两区，来源以 `[[笔记]]` 链接给出。
- 可以**在同一会话里继续追问**（「那后来呢？」），上下文自动带上之前引用过的来源；会话保存在本地浏览器（最多 10 个），可新建/切换/重命名/删除。
- 模型不可用时显示可见错误说明，不会白屏。

## 5. 「项目」页（全部项目管理）

- 列出 `~/Documents/Work` 下**全部项目文件夹**（不只工作台上的），每行带状态徽标：**在工作台**（绿）／**新**（黄，还没建档）／**已归档**（灰）。
- 顶部搜索框按项目名过滤；列表排序为 在工作台 → 新 → 已归档。
- 行内操作：
  - **加入工作台**：未建档的「新」项目会建档并上首页；已归档的项目点它即**恢复**。
  - **归档**：把在工作台的项目归档（下首页）。归档/恢复只改 `_vault` 里的项目档案状态，**文件夹和 git 历史一概不动**。

## 6. 状态与提醒

- 顶栏健康点：绿色=正常，橙色=有积压/接近预算，红色=有异常（失败任务或飞书授权失效）。
- 页面每 60 秒自动刷新一次；也可点右上角 ↻ 手动刷新。
- 系统会在**待确认积压 / 费用超预算 / 定时任务失败**时自动发 macOS 通知提醒你（无需任何操作）。

## 7. 数据都在本地

- 快速捕捉 → `_vault/inbox.md`（带分类标记）。
- 会议导入 → `_vault/meetings/transcripts/`（原文）+ `_vault/meetings/notes/`（结构化笔记）+ `_vault/review/meetings.md`（待确认候选）。
- 审批应用 → 项目主笔记 / 飞书任务 / inbox + `_vault/review/archive/` 审计。
- 项目在工作台/归档状态 → `_vault/projects/<项目>.md` 主笔记的 `status` 字段（`active` / `archived`）。
- 全部是 Markdown + 本地文件（位于 `~/Documents/Work/_vault/`），随时可以用 Obsidian 打开查看、继续编辑。

## 8. 常见问题

**Q：双击图标没反应 / 页面打不开？**
A：工作台是后台代理、**没有 Dock 图标**，从「应用程序」打开后若浏览器窗口没弹出来，手动访问 http://127.0.0.1:8787。仍不行可看日志 `~/Library/Logs/summitworkbench-panel.log`。

**Q：页面是旧的样子（白底表格、没有卡片）？**
A：依次检查：
1. 退出面板（网页顶栏「退出」）后**重新从「应用程序」打开 SummitWorkbench**——版本更新只在
   服务重启后生效；
2. 若仍旧，在面板页面按 **⌘⇧R 强制刷新**（浏览器可能缓存了旧页面，而旧页面引用的文件已
   被新版本替换）；
3. 确认你打开的是 **/Applications/SummitWorkbench.app**（本仓库产物，与仓库自动链接），不是
   /Applications 里的 SummitKnowledge / SummitServerAI——那两个是历史遗留旧产品，内嵌旧界面，
   与本仓库无关；
4. 还不行则是前端产物没重建（找维护者执行一次 `cd web && npm run build` 并重启服务）。

**Q：明明工作目录里有很多项目文件夹，首页「项目推进」却很少/是空的？**
A：首页只显示**已建档且在工作台**的项目。未建档的文件夹会先出现在「新文件夹」横幅里，点「加入工作台」后才会成为推进卡；已归档的进不了首页。全部文件夹都能在「项目」页找到并管理。

**Q：快速捕捉一直显示「想法」？**
A：AI 分类需要模型配置（`[models.capture]` 或 `[models.shared]` + Keychain 里的 API key）。没配置时功能照常用，只是不分类、不识别截止日期。

**Q：拖入文件提示「未识别为逐字稿」？**
A：需要 `.md` / `.txt` 且内容非空；请确认导出的是逐字稿正文而非空模板。

**Q：导入或问答报「模型未配置」？**
A：这两项依赖云端模型。未配置时它们暂不可用，但捕捉、审批、简报生成等其余功能不受影响。配置好后重启 App 即可。

**Q：修改审批候选后想撤销？**
A：用「↺ 改回待确认」或直接编辑回原值；审批页只改 `meetings.md`，不会触发任何写回。

**Q：任务在哪里点完成——工作台还是飞书？**
A：**两边都行，且双向同步**：在「今日」简报的待办任务行尾点小圆钮「✓」，会直接写回飞书把任务标记完成，该行随即消失、计入「最近完成」；在飞书里完成的任务，也会在下次简报生成（或刷新后重新生成简报）时反映——工作台把飞书当作任务状态的唯一真源。

**Q：为什么任务完成操作偶尔提示失败？**
A：一键完成需要飞书授权有效且任务仍存在（例如已删除的任务会失败）。失败时本地不做任何改动，按提示处理（如重新授权）后重试即可。

## 9. 一句话总结

**每天：捕捉框记一笔 → 看审批卡片批一轮 → 把新会议的逐字稿拖进去 → 简报/问答兜底；
首页只盯你在工作台的项目，其余在「项目」页随时可取回。**
