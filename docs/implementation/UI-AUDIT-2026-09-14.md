1. **提问 / 审批的来源按钮**以 `路径#区块` 为文字与来源行（`ask/render.ts`、`review/render.ts:sourceLink`）

4. **设置页工作区路径、诊断包文件清单、`~/Library/Logs`、模型 ID / 服务地址** —— 高级 / 维护区。
