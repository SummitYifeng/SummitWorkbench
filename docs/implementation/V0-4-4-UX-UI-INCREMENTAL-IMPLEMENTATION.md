## 下一阶段起点与未完成清单

### 优先继续优化的实现项

1. **审批筛选与批量选择**：增加状态筛选、复选框选择、选择范围摘要和切换筛选时清空选择；保留现有“检查并写回”预演，不增加旁路写回。
2. **冲突弹层收口**：让同步冲突详情复用草稿关闭保护、统一焦点初始化/归还，并用合成分叉工作区覆盖预检、选择校验和稍后处理。
3. **项目详情体验**：在项目页内提供详情视图和明确“返回项目”，再补从今日进入、返回后筛选/滚动位置恢复。
4. **导入回执验收**：使用隔离合成逐字稿覆盖成功、失败、部分失败、软预算提醒、关闭后重开、多文件拖入和幂等重复导入。

### 已有实现但尚未完成真实验证

- 320/390/768/960/1280 宽度、200% 缩放、深浅主题、减少动态效果下的完整布局与可读性。
- 六页签完整键盘巡航、所有弹层初始焦点/Tab 约束/Escape/返回焦点，尤其是同步冲突、日志和产物编辑弹层。
- 审批一次点击一次请求、部分失败保留失败项、unknown 不自动重试，以及审批页真实来源打开。
