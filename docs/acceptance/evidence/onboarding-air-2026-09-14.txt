一、现象（使用者在 Air 上首启，build 42）
================================================================================
按作业单填完「从另一台 Mac 克隆」四项（含新建的细粒度 PAT）后，界面只显示一句英文：

    The string did not match the expected pattern.

================================================================================
二、真实原因（来自 Air 的 ~/Library/Logs/summitworkbench-server.log）
================================================================================
ERROR:    Exception in ASGI application
Traceback (most recent call last):
  ...
  File "summit_workbench/webapp/routers/onboarding.py", line 243, in restricted_remote_stage
  File "pathlib.py", line 1406, in expanduser
RuntimeError: Could not determine home directory.

三层叠加：
1. 「目标文件夹」填的是 `~用户名` 形式，而该用户在 Air 上不存在。
   `posixpath.expanduser` 对未知用户**返回原串**，`pathlib` 于是抛 RuntimeError。
   （本地对照：`Path("~gandalf/x").expanduser()` 抛出的文案与日志**逐字相同**；
   而 `Path.home()` 一切正常——这解释了为什么服务能正常启动、只有这一步炸。）
2. 首启向导跑的是**受限 app**，它当时**只装 422 处理器**，没有兜底 → 异常漏到 uvicorn。
3. 向导的 `api()` **无条件 `response.json()`** → 非 JSON 响应 → WebKit 抛
   `SyntaxError: The string did not match the expected pattern.` → 真实原因彻底不可见。

================================================================================
三、一次被实测否证的推断（诚实记录，避免下次重走）
================================================================================
中途据「冻结包 _internal 里没有 pwd」推断「进程没有 HOME 且 CPython 的 passwd 兜底不可用」，
并据此提出「打包 pwd」的修法。用冻结包实测否证：

    $ env -u HOME .../SummitWorkbenchServer --kb-diagnostic
    {"bm25_fallback_hit": [...], "fts5_trigram": true, "sqlite_version": "3.53.1"}
    $ env -u HOME <同样的服务> ...          # 仍能启动，且仍解析出 workspace_id=fb9494a4-…
    → 说明 pwd 可用、Path.home() 可用；「没有 HOME」不是本次原因。

该修法已撤回，未写进代码。

四、改了什么（四层一起修）
================================================================================
- config/paths.py：新增 UserPathError + resolve_user_path()（使用者输入路径的唯一解析入口）。
  ~ / ~/… 按「显式 home > Path.home() > $HOME > passwd」解析；~用户名 解析不了 → 可显示文案。
  **绝不**退回「当作当前用户」。
- webapp/routers/onboarding.py：9 处 Path(...).expanduser() 全替换；PAT 改用 _pat_secret() 去空白。
- webapp/request_boundary.py：install_validation_handler 同时装 UserPathError → 400；
  新增 install_unexpected_handler() 并**在受限 app 也安装**。
- webapp/onboarding_view.py：api() 先读 text 再 JSON.parse，非 JSON 报「HTTP 状态 + 片段」；
  pat 补 .trim()。
